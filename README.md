# NewGameLaunchPredict

新玩法上线前的受众重叠度分析与转化预估工具（离线可运行 Demo）。

## 功能

- 上传玩法列表（`玩法ID,玩法名`，支持 CSV / TXT / JSON，最多 8 个），自动生成种子人群（灰度转化 + 竞品近 30 天参与）
- 以种子玩家特征在近 90 天活跃池中做相似召回，得到潜在受众
- 选择宣推周期（7 / 14 / 30 天或自定义），预估周期内去重活跃人群与分层结构
- 与存量已上架玩法、同批次新玩法的重叠度匹配，三类人群互斥拆解（存量占用 > 同批次 > 自由可触达）
- 分人群转化预估（2r / 0.8r / 0.6r / 0.2r）+ 新玩法重叠热力矩阵 + CSV 导出

## 运行

纯静态页面，无需构建与依赖：

```bash
python -m http.server 8901
# 打开 http://127.0.0.1:8901/index.html
```

也可直接双击 `index.html`。

## 目录

| 路径 | 说明 |
|---|---|
| `index.html` / `styles.css` | 四步工作台页面与样式 |
| `js/sim.js` | 离线模拟引擎：520 万大盘口径，26 万虚拟玩家集合真实求交，展示按 20 倍外扩 |
| `js/app.js` | 列表解析、渲染、转化预估与 CSV 导出 |
| `docs/api.md` | 接入真实后端所需的接口规格（12 个接口 + 字段映射 + 验收断言） |

## 说明

演示数据为确定性模拟（同一 `game_id` 结果稳定），不含真实用户信息。接入生产环境时，按 `docs/api.md` 替换 `js/sim.js` 中的召回、活跃预测与交集计算，并去掉展示层 20 倍外扩即可。
